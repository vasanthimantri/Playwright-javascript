# Playwright JavaScript

JavaScript practice exercises covering language fundamentals, operators, and small expression challenges. The repository currently contains standalone scripts; it does not include a Playwright test suite or package-managed tooling.

## Contents

- `Javascript_class1/` - Hello world and basic math
- `Javascript_class 2/` - Keywords, naming conventions, and comments
- `Javascript_class 3/` - Literals, numbers, `null`, `undefined`, and special numeric values
- `Javascript_class4/` - Arithmetic, assignment, and comparison operators
- `13-oct-Operator IQ/` - Nullish coalescing, strings, and ternary operator exercises
- `Task_13-oct/` - Increment and decrement expression exercises

## Run an exercise

Install [Node.js](https://nodejs.org/) and run a script from the repository root:

```sh
node "Javascript_class1/01_Helloworld.js"
```

Each file is independent, so run the exercise you want to try. Some files in `13-oct-Operator IQ/` and `Task_13-oct/` do not have a `.js` extension; pass their paths to Node.js in the same way, for example:

```sh
node "13-oct-Operator IQ/Nullish_operator"
```
